**Assignment:** Visual Studio 2.1

**Prompt A:** Create a drawing that uses colored pencil to emphasize the lines, shapes, textures and movement of a bird perched on a tree branch. Use curved and diagonal lines to define the feathers and the tree branch implying movement. Use organic shapes for the birds body, wings and beak. The colored pencil should use the technique of cross-hatching to emphasize the textures of the feathers and bark of the tree branch. 

**Prompt B:** Create a linocut print that uses linoleum to emphasize the lines, shapes, textures and movement of a bird perched on a tree branch. Use curved and diagonal lines to define the feathers and the tree branch implying movement. Use organic shapes for the birds body, wings and beak. The linocut print should use high contrast shapes and bold carved lines to emphasize the textures of the feathers and bark of the tree branch.
